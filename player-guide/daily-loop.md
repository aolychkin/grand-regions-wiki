## Этап 1: Первая неделя — устроиться на работу

> ⚠️ **В текущем MVP механики работы ещё нет** (планируется в спеке 8.8 `player-jobs-and-wages`). Сейчас игрок получает только стартовый капитал. Работа за ЗП — следующая спека.

🟡 Спека 8.8 (BLOCKING).

**Цель:** найти работу в своём городе → получать ЗП каждый тик → накопить 200k-500k ₽ на покупку первой Territory.

**Что делать каждый день (после реализации спеки 8.8):**

| Экран | Действие | Что получаешь |
|---|---|---|
| `/profile` или `/jobs` | Смотришь вакансии в своём городе. На каждом Building есть N job-slots | Список доступных мест работы |
| `/profile` → «Устроиться» | Выбираешь работу: можно у `city_gov` (стабильно) или у `private_player` (дороже, риск увольнения) | `PlayerJob` в БД |
| `/profile` → «Моя работа» | Смотришь свою ЗП за день, накопленный опыт | Оценка темпов накопления |
| `/home` | Смотришь сводку: бюджет города, голод, энергия | Понимание ситуации в городе |
| `/finance` | Смотришь рынок: какие ресурсы дорогие | Где есть спрос → где открывать бизнес |
| `/map` → твой город | Изучаешь, какие лоты Territory свободны | Куда метить под бизнес |

**Как работает заработок** (планируется в 8.8):

> 💡 **Принцип:** активный grind. Заходишь на завод → выбираешь сколько энергии потратить (слайдер 1-100) → **сразу получаешь ₽** + завод получает ресурс в свой output. Энергия становится 0, восстанавливается медленно.

- Откроешь `/jobs` (или тапнешь Building в `/buildings`) → «Поработать».
- В UI слайдер: «Потратить **X энергии** на работе» (от 1 до текущей).
- Подтверждаешь → транзакция:
  - **₽ → твой кошелёк** (X × 100 × skill_modifier).
  - **Ресурс → output завода** (X × output_per_energy кг в склад).
  - Энергия = (старая − X).
- Без энергии работать нельзя — только отдыхать.
- Восстановление: **12.5 ед/час** → полные 100 за 8 часов реал-покоя.
- Полный пакет 100 энергии: базовый ~10 000 ₽, прокачанный ~30 000 ₽.

**Скилл-модификатор:**
- `Knowledge` ↑ → ↑ ставку (учёба в Школе/Академии — спека 11.5).
- `Strength`, `Endurance` ↑ → ↑ ставку (физический труд).
- При full skill (10/5/5) → ×3.0 от базового.

**Стратегия:**
- Хочешь много заработать сейчас → жми full 100 энергии за раз.
- Хочешь играть несколько раз в день → меньшие пакеты (15-30 энергии каждые часы).
- Хочешь экономить энергию для других механик (политика, война) → меньше работай.

**Чем отличается от руководителя:**

| | 🔧 Рабочий | 🎩 Руководитель (спека 11) |
|---|---|---|
| Что тратит | Энергию (1/тик пассивно) | Энергию (~5 за визит-сбор) |
| Что получает | Доля производства за тик | Ресурс с **buffer'а завода** (батч-сбор) |
| Бафф зданию | — | +15-30% к производству пока есть рук-ль |
| Цель | Стабильный поток ресурса | Контроль + большие батчи |
| Если не зашёл | Ничего страшного — просто не работаешь | **Завод останавливается** когда buffer полон ⚠️ |

Один игрок может быть на одном заводе рабочим, а на другом руководителем.

**Активный геймплей руководителя (спека 11):**

```
Завод производит → buffer наполняется → ты заходишь:
  • Тратишь ~5 энергии
  • Снимаешь N кг (N = base × (1 + level/10) × (1 + Strength/10))
  • Ресурс → твой личный склад
  • Buffer освобождается → производство продолжается
```

Чем выше **уровень + Strength + Endurance** — тем больше снимаешь за один визит. Прокачанный игрок может ходить раз в день и снимать всё, начинающий — каждый час по чуть-чуть.

**Альтернативы (если не хочется ходить):**
- 💰 Нанять **NPS-водителей** за ₽ — постоянная зарплата, автомат вывозит M кг/день. Меньше прибыли, но не нужно заходить.
- ⭐ Купить **GP-ускоритель/Помощника** (W7 спека 16) — пропускная способность ×2 на 24/72/168 часов.

Это даёт **выбор active / passive / premium**:
| Стиль | Прибыль | Время игрока |
|---|---|---|
| Active (заходишь сам) | 100% | Высокое — каждые часы |
| Passive (NPS-водители) | ~70% (минус ЗП NPS) | Низкое — раз в день check |
| Premium (GP) | 100% + ускорение | Минимальное — купил пакет |

**Где работать выгоднее (как рабочий):**

| Работодатель | Что получаешь | Когда выгодно |
|---|---|---|
| `city_gov` (мэрия) | Стандартный output × skill_modifier | Стабильно, нет риска закрытия |
| `private_player` (предприниматель) | То же + возможный бонус | Может закрыться если убыточен |
| Завод с дефицитом твоего класса | +20% бонус выработки | Краткосрочно — большая выгода |

> **Важно:** на этом этапе ты **обычный житель**. Никаких классов нет — можешь параллельно вступить в партию (lvl 1+), баллотироваться в депутаты (lvl 10+) и копить на бизнес одновременно. Работа = пассивный доход, остальное — параллельные активности.

## Этап 2: Открыть свой бизнес

🟡 Спека 19.5 (`territory-and-auction`) + спека 6 (полная реализация Building lifecycle).

**Цель:** купить Territory, построить частный завод, начать получать прибыль.

### Шаг 2.1: Выбрать город и лот

| Экран | Действие |
|---|---|
| `/map` | Тапаешь на свой или соседний город → плашка с инфой |
| `/map` → город → «Детали» | (POST-MVP) Видишь сетку лотов 1 км². Серые = свободны. Цены показаны |
| `/finance` | Сравниваешь рынки разных городов — где выгоднее открыть |

**Стратегия выбора:**
- Дешёвый лот на периферии → выгоднее по цене покупки.
- Дорогой лот в центре → больше клиентов, выше прибыль.
- Города с нехваткой ресурса (например мало хлеба → строй пекарню) — ↑↑ прибыль.

### Шаг 2.2: Купить Territory

🟡 Не реализовано (спека 19.5).

- Тапаешь на свободный лот → видишь цену → подтверждаешь покупку.
- Деньги уходят в бюджет города. Лот становится твоим (`Territory.OwnerKind=private_player`).

### Шаг 2.3: Построить здание

🟢 Каталог зданий есть. 🟡 Полный workflow стройки — спека 6.

| Экран | Действие |
|---|---|
| `/buildings` | Выбираешь тип здания (например `iron_smelter`) |
| `/buildings/:code` | (POST-MVP) Видишь детали: ресурсы для стройки, ЗП персонала, окупаемость |
| `/buildings` → «Построить» | Указываешь Territory + начинаешь стройку |

**Что нужно для стройки:**
- 5 видов ресурсов (см. [Construction](../game-mechanics/construction.md)).
- Бригада (строители + архитекторы) — нанимаются автоматически из NPS.
- Деньги на стройку (~1-7 млн ₽ для типичного завода).
- Срок (10-30 минут реального времени = 1-3 игровых месяца).

### Шаг 2.4: Запустить производство

После завершения стройки:
- Здание получает статус `operating`.
- Тик начисляет производство в склад → продажа на рынке (через `/finance`).
- Платишь налоги: 15% городу + 5% стране, **80% себе**. См. [Налоги](taxes.md).

**Куда смотреть:**
- `/profile` → раздел «Активы» — твои здания.
- `/finance` → «История» — все продажи и доходы.
- `/map` → твой город будет с золотым dashed-контуром (есть приватные активы).

## Этап 5: Президент / основание государства

🟡 Спека 19 (`independence-paths`).

**Два пути:**

### А. Длинный путь — через выборы

- lvl 50+.
- Партия выдвигает тебя кандидатом.
- Прямые общенациональные выборы.

### Б. Быстрый путь — основание государства

> 💡 На старте мира **никаких государств нет**. Кто первая партия захватывает регион — тот и Президент.

- Собираешь партию.
- Готовишь армию.
- Атакуешь NPC-армию любого нейтрального региона (для первого захвата соседство не нужно).
- Захват удался → партия становится правящей, лидер партии = Президент. Захваченный регион = столичный регион. Захваченный город (regional_capital) = столичный город.

**Бонус:** все налоги, что копились в спящей Country с момента старта мира, переходят к тебе.

См. [Пути к власти](paths-to-power.md) для деталей.

## Сравнение: бизнес vs стройка региона

Главное различие — **владелец здания** и **куда идёт прибыль**.

| | Свой бизнес (предприниматель) | Стройка региона (мэр) |
|---|---|---|
| **Владелец здания** | `private_player` | `city_gov` |
| **Где строится** | На купленной Territory (private) | На Territory мэрии (city_gov) |
| **Кто платит за стройку** | Ты (личные деньги) | Бюджет города |
| **Куда идёт прибыль** | 80% — тебе, 15% городу, 5% стране | 90% — в `City.Budget`, 10% стране |
| **Какие здания строишь** | Любые (заводы, магазины, газеты) | Любые + социальные (школы, больницы) |
| **Цель** | Личное богатство | Развитие города + переизбраться |
| **Управляет работой** | Ты сам или бот-директор | Назначенный министр или бот |

**Совет:** хороший мэр **сам остаётся предпринимателем** — у него и личный бизнес, и муниципальный бюджет. Это нормально (если не нарушает `OQ-17` про конфликт интересов).

## Краткий ответ на вопрос «что мне делать сейчас»

```
0. Зарегистрировался → /profile (посмотри себя)
1. Каждый день →
     /home — общая обстановка
     /finance — рынок (где спрос)
     /map — куда расти (свой город / соседи)
2. Когда накопил денег →
     /map → выбираешь лот
     /buildings → выбираешь тип здания
     Строишь свой бизнес
3. Когда уровень 10+ →
     Вступи в партию через /profile
     Выдвигайся в депутаты
4. Когда уровень 20+ →
     Кампания в мэры
     Управляешь городом через /stats
5. Когда хочешь власти →
     /map → бери партию → захватывай нейтральный регион
     Становишься Президентом если первый
```
