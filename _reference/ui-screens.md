В нижней панели Telegram Mini App **5 разделов**, переключение тапом по иконке. Дополнительные экраны (Карта России, карточка здания) открываются по кнопкам с этих главных. В Telegram Mini App нет команд через `/`, только тапы по интерфейсу.

```
[ 🌐 Обзор ] [ 🔨 Стройка ] [ 💼 Финансы ] [ 📊 Статы ] [ 👤 Я ]
```

## Основные разделы

### 🌐 Обзор 🟢

Точка входа: что происходит в твоём мире и городе.

- **Карточка «Карта России»** с одной кнопкой-переходом на отдельный экран карты.
- **Мир:** страна, регион, президент, сколько регионов открыто.
- **Игроки:** в России, в твоём городе, онлайн сейчас.
- **Мой город:** имя, население, количество построек, уровень голода. Кнопка «Подробная статистика» ведёт в «Статы».
- **Общие события:** появление мэра, тестовая фаза MVP, заглушки голосований и инцидентов.
- **Чаты:** заглушки чатов города, региона, партий (POST-MVP).
- **Статьи и новости:** заглушки публикаций политиков и декретов региона (POST-MVP).

### 🔨 Стройка 🟢

Каталог всех типов зданий по секторам.

- Вкладки секторов: **Ресурсы / Пища / Жильё / Сервисы / Энергия / Коммерция / Войска**.
- Capacity bar сверху показывает лимиты твоего города.
- На карточке здания: иконка, что производит и сколько в день, стоимость стройки в ₽ и ресурсах, сколько рабочих нужно, окупаемость.
- 🟡 Стройка здания через выбор лота на карте: POST-MVP.

### 💼 Финансы 🟢

Бот-рынок и история сделок.

- Цены на все 21 ресурс.
- **Продать боту** ×0.5 от рыночной цены: быстрый выход в кеш.
- **Купить у бота** ×5 от рыночной цены: быстрый закуп если на рынке нет предложений от игроков.
- История твоих сделок.
- 🟡 Выставить оффер другим игрокам: POST-MVP.

### 📊 Статы 🟢

Статистика твоего города.

- **Занятость:** сколько мест в зданиях, сколько занято, дефицит рабочих.
- **Население по классам:** низший / средний / строители / архитекторы и др.
- **Ресурсы города:** сколько на складах, динамика (+/− за день).
- **Постройки:** список с владельцами и состоянием.
- 🟡 Расширенный контроль для мэра (ставки налогов, цены лотов, министры): POST-MVP.

### 👤 Я 🟢

Личный профиль игрока.

- **Карточка:** аватар, имя, уровень, навыки (Знания / Сила / Выносливость), прописка.
- **Финансы:** ₽, GP, энергия / максимум.
- **опыт:** прогресс прокачки активного навыка.
- **История последних сделок.**
- **Logout.**
- 🟡 Активы (заводы, лоты), действующие должности, теги активности, переключение активного навыка, история налогов: POST-MVP.

## Дополнительные экраны

### Карта России 🟢

Открывается с «Обзора» по карточке «Карта России». Полноэкранная карта с pan / zoom двумя пальцами.

- **Цвета:** 🩶 серый: нейтральный регион, 🔵 синий, занят твоей страной, 🔴 красный, занят чужой страной.
- **Иконки:** 👑 на столице региона, 🏠 на твоём городе прописки.
- **Тап по региону** показывает плашку с деталями (название, население, площадь, мэр, партия).
- 🟡 POST-MVP: сетка лотов 1×1 / 5×5 / 20×20 км на максимальном zoom, подсветка свободных лотов, подсветка регионов доступных к захвату.

### Карточка здания 🟢

Открывается тапом по конкретному зданию в «Стройке».

- Владелец: мэрия / игрок / государство.
- Состояние: работает / повреждено / стройка.
- Производство и склад завода.
- Накопленный опыт.
- Сотрудники.
- 🟡 POST-MVP: прокачка через опыт, найм / увольнение, изменение типа оплаты.

### Игровое время в хедере 🟢

В правом верхнем углу всегда видно компактные часы. Тап даёт тултип:

```
📅 Игровое время: 07:00, день 14, год 3
   1 тик (1 мин реал) = 1 игровой час
   1 игровой день = 24 минуты реал
   1 игровой год ≈ 6 дней реал
   Сезон: лето
   Следующий тик через 0:25
```

Единственное место в UI где объясняется конвертация. В остальных экранах всё в игровых днях.

## Push-уведомления

Telegram шлёт пуши:

- За 1 игровой день до истечения скоропортящегося товара на складе.
- При появлении просрочки.
- При начале голосования в Гордуме / Госдуме (если ты депутат).
- При объявлении войны твоей стране / партии.
- При выкупе или нападении на твою территорию.

Настройки уведомлений: «Я» → Уведомления (POST-MVP).
