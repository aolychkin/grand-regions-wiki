В нижней панели 5 основных разделов, переключение тапом по иконке. Дополнительные экраны (Работа, Статистика, карточка здания) открываются по кнопкам с этих главных.

```
[ 🏠 Главная ] [ 🗺 Карта ] [ 🏭 Постройки ] [ 💰 Финансы ] [ 👤 Профиль ]
```

> 💡 В Telegram Mini App **нет команд через `/`**, только переходы по интерфейсу. Когда в гайдах написано «зайди в раздел Работа», это значит тапнуть по кнопке в UI, не вводить команду.

## Основные разделы

### 🏠 Главная 🟢

Сводка:
- KPI мира: твоя страна (или «государств нет»), регион, президент.
- KPI города: бюджет, население, голод.
- Карточка карты, тап ведёт в раздел **Карта**.
- Голосования, если ты депутат (POST-MVP).
- Быстрая ссылка на бюджет, если ты мэр.

Для новичка это основной экран чтобы понять «что происходит».

### 🗺 Карта 🟢

Карта России с регионами и городами. В MVP открыты Москва (12 округов) и Подмосковье (56 городов).

**Цвета:** 🩶 серый, нейтральный регион, 🔵 синий, занят твоей страной, 🔴 красный, занят чужой страной.

**Иконки:** 👑 на столице региона, 🏠 на твоём городе прописки.

**Действия:** тап по региону открывает плашку (название, население, площадь, мэр, партия), pan / zoom двумя пальцами.

**POST-MVP:** сетка лотов 1×1 / 5×5 / 20×20 км на максимальном zoom, подсветка свободных лотов для предпринимателей, подсветка регионов доступных к захвату для воинов.

### 🏭 Постройки 🟢

Каталог всех 27 типов зданий. Вкладки по секторам: Ресурсы / Пища / Энергетика / Жильё / Сервисы.

На карточке здания: иконка + название, что производит и сколько в день, стоимость стройки (ресурсы + ₽), сколько рабочих нужно, окупаемость.

**Действия:** тап открывает детали. «Построить» (POST-MVP): выбор лота + начало стройки.

### 💰 Финансы 🟢

Бот-рынок: цены на все 21 ресурс, скупка ботом ×0.5 от рыночной (быстро продать), продажа ботом ×5 от рыночной (быстро купить). Твои офферы (если выставил) и история сделок.

**Действия:** «Продать боту» и «Купить у бота», мгновенно. Выставить оффер другим игрокам, POST-MVP.

### 👤 Профиль 🟢

Карточка: имя, аватар, уровень, навыки, прописка, финансы (₽, GP, энергия), активы (заводы и лоты по городам), действующие должности, теги активности (предприниматель / работник / политик / участник ЧВК).

**Действия (POST-MVP):** публичный профиль другого игрока, перевести деньги, сменить активный навык, сменить прописку.

## Дополнительные экраны

### Работа 🟡

Открывается из Главной или Профиля. Список всех вакансий в твоём городе:
- Заводы с открытыми слотами.
- Условия каждого: тип оплаты (cash / share / mixed), ставка, количество мест.
- Расчёт твоей выгоды с учётом навыков.
- «Поработать»: слайдер «сколько энергии вложить», деньги или ресурс приходит сразу.

### Статистика города 🟡

Открывается из Главной → «Подробнее о городе». Детали родного города или города в управлении (если ты мэр):
- Население по классам.
- Удовлетворённость, голод, достаток.
- Производство и потребление.
- Бюджет и налоги.
- Гордума: состав, голосования.

Доступ по ролям: жители видят базовую статистику, мэр получает полный контроль (бюджет, ставки, цены лотов, министры), губернатор то же на уровне региона.

### Карточка здания 🟢

Открывается из **Постройки** тапом по конкретному зданию. Внутри: владелец (мэрия / игрок / государство), состояние (работает / повреждено / стройка), производство и склад завода, накопленный XP, сотрудники.

**Действия (POST-MVP):** прокачка через XP (+5% производства, +10% склада и т.д.), найм / увольнение, изменение типа оплаты.

## Иконка часов 🟢

В правом верхнем углу игровое время. Тап даёт тултип:

```
📅 Игровое время: 07:00, день 14, год 3
   1 тик (1 мин реал) = 1 игровой час
   1 игровой день = 24 минуты реал
   1 игровой год ≈ 6 дней реал
   Сезон: лето
   Следующий тик через 0:25
```

Единственное место в UI где объясняется конвертация. В остальных экранах всё в игровых днях («100 кг/день», «20k ₽/день», «2 дня до истечения»).

## Push-уведомления

Telegram шлёт пуши:
- За 1 игровой день до истечения скоропортящегося товара на складе.
- При появлении просрочки.
- При начале голосования в Гордуме / Госдуме (если ты депутат).
- При объявлении войны твоей стране / партии.
- При выкупе или нападении на твою территорию.

Настройки в Профиле → Уведомления (POST-MVP).
