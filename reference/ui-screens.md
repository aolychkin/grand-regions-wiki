# Экраны Telegram Mini App

Все экраны в игре. Сначала тебя пускает в `/home`, дальше навигация через нижнюю панель (bottom nav).

## Навигация

В нижней панели Telegram Mini App 5 основных вкладок:

```
[ 🏠 Главная ] [ 🗺 Карта ] [ 🏭 Постройки ] [ 💰 Финансы ] [ 👤 Профиль ]
```

Дополнительные экраны открываются по тапу с этих главных.

## `/home` — Главная

> 🟢 Работает в MVP.

Что видишь:
- **KPI мира** — твоя страна (или «нет страны»), регион, президент.
- **KPI города** — бюджет, население, голод (если есть).
- **Карточка карты** — тапаешь, попадаешь на `/map`.
- Голосования (если ты депутат, в работе — спека 9).
- Быстрые ссылки на бюджет (если ты мэр).

Для новичка — основной экран чтобы посмотреть «что в мире происходит».

## `/map` — Карта России

> 🟢 Работает в MVP.

Полноэкранная карта с регионами и городами:

- **Регионы** — Москва (12 округов как города) + Подмосковье (56 городов) в MVP. Остальные регионы — добавятся.
- **Цвета:**
  - 🩶 Серый — нейтральный регион (никем не занят).
  - 🔵 Синий — занят твоей страной.
  - 🔴 Красный — занят другой страной.
- **Иконки** — 👑 на столице региона, 🏠 на твоём городе прописки.

Управление:
- Тап по региону — плашка с инфой (название, население, площадь, мэр, партия).
- Pan / zoom — двумя пальцами или drag.
- Sticky preview — плашка снизу с метриками.

В будущем (POST-MVP):
- Сетка лотов 1 км² на максимальном zoom.
- Подсветка свободных Territory для предпринимателей.
- Подсветка регионов доступных к захвату для воинов.

## `/buildings` — Постройки

> 🟢 Каталог работает. 🟡 Стройка с Territory — POST-MVP (спека 19.5).

Что видишь:
- **Каталог** всех 27 типов зданий.
- **Вкладки по секторам:** Ресурсы / Пища / Энергетика / Жильё / Сервисы.
- На каждой карточке:
  - Иконка + название.
  - Что производит и сколько в день.
  - Стоимость стройки (ресурсы + ₽).
  - Сколько работников нужно.
  - Окупаемость.

Действия:
- Тап на карточку → детали здания.
- Кнопка «Построить» (POST-MVP, спека 19.5) → выбор Territory + начало стройки.

## `/finance` — Финансы

> 🟢 Работает в MVP.

Что видишь:
- **Бот-рынок** — текущие цены на 21 ресурс.
  - Скупка ботом (×0.5 от рыночной) — быстро продать.
  - Продажа ботом (×5 от рыночной) — быстро купить.
- **Твои офферы** (если выставил).
- **История сделок** — все твои покупки/продажи.

Действия:
- «Продать ресурс боту» — мгновенно.
- «Купить ресурс у бота» — мгновенно (если есть деньги).
- Выставить оффер другим игрокам (POST-MVP).

## `/profile` — Личная страница

> 🟢 Работает в MVP.

Что видишь:
- **Карточка игрока:** имя, аватар, уровень, навыки, прописка.
- **Финансы:** ₽, GP, энергия / максимум.
- **Активы:** твои Building и Territory (с разделом по городам).
- **Должности:** действующие PlayerPosition.
- **Теги активности:** entrepreneur / worker / politician / pmc_member / ...

Действия:
- Просмотр публичного профиля другого игрока (`/profile/:player_id`) — POST-MVP (спека 8.9).
- «Перевести деньги другому игроку» — POST-MVP (спека 8.9).
- «Сменить активный навык» — POST-MVP (спека 11.5).
- «Сменить прописку» — POST-MVP.

## `/jobs` — Рынок труда

> 🟡 POST-MVP (спека 8.8, следующая в плане).

Все вакансии в твоём городе:
- Список всех заводов с открытыми слотами.
- Условия каждого: тип оплаты (cash / share / mixed), ставка, количество мест.
- Расчёт твоей выгоды с учётом навыков.
- Кнопка «Поработать» — слайдер «сколько энергии вложить» → деньги или ресурс приходит сразу.

## `/stats` — Статистика города

> 🟡 POST-MVP.

Детали твоего города или города в управлении (если ты мэр):
- Население по классам.
- Удовлетворённость / голод / достаток.
- Производство и потребление.
- Бюджет и налоги.
- Гордума (состав, голосования).

Доступ зависит от роли:
- **Все жители** — видят базовую статистику.
- **Мэр** — полный контроль (бюджет, ставки налогов, цены Territory, министры).
- **Губернатор** — то же на уровне региона.

## `/buildings/:id` — Карточка конкретного здания

> 🟢 Просмотр работает. 🟡 Управление XP/прокачкой — POST-MVP (спека 11.6).

Что видишь:
- Owner (city_gov / private_player / country_gov).
- Текущее состояние (operating / damaged / construction).
- Production и Buffer (заполнение склада завода).
- XP накопленный.
- Сотрудники.

Действия (POST-MVP):
- Прокачка завода через XP (+5% production, +10% buffer, +15% wage_modifier и т.д.).
- Найм / увольнение работников.
- Изменение wage_mode.

## Иконка часов в хедере

> 🟢 Работает в MVP.

В правом верхнем углу — компактные часы текущего игрового времени. Тапнешь → раскроется тултип:

```
📅 Игровое время: 07:00, день 14, год 3
   1 тик (1 мин реал) = 1 игровой час
   1 игровой день = 24 минуты реал
   1 игровой год ≈ 6 дней реал
   Сезон: лето (зимний через ~2 реал-дня)
   Следующий тик через 0:25 ⏱️
```

Это единственное место в UI где объясняется конвертация игрового времени в реальное. В остальных местах ты видишь «100 кг/день», «20k ₽/день», «2 дня до истечения» — всё в игровых днях.

## Push-уведомления Telegram

Игра шлёт пуши через TG в нескольких случаях:

- За 1 игровой день до истечения скоропортящегося товара на твоём складе.
- При появлении просрочки на складе.
- При начале голосования в Гордуме / Госдуме (если ты депутат).
- При объявлении войны твоей стране / партии.
- При выкупе или нападении на твою Territory.

Настройки уведомлений — `/profile → Уведомления` (POST-MVP).
