# Разделы Telegram Mini App

В нижней панели — 5 основных разделов. Переключение тапом по иконке.

```
[ 🏠 Главная ] [ 🗺 Карта ] [ 🏭 Постройки ] [ 💰 Финансы ] [ 👤 Профиль ]
```

Дополнительные экраны (Работа, Статистика города, карточка здания) открываются по кнопкам с этих главных.

> 💡 В Telegram Mini App **нет команд через `/`** — только переходы по интерфейсу. Когда в гайдах написано «зайди в раздел Работа», это значит тапнуть по кнопке в UI, не вводить команду.

## 🏠 Главная

> 🟢 Работает в MVP.

Сводка:
- KPI мира — твоя страна (или «государств нет»), регион, президент.
- KPI города — бюджет, население, голод (если есть).
- Карточка карты — тап ведёт в **Карту**.
- Голосования, если ты депутат (POST-MVP).
- Быстрая ссылка на бюджет, если ты мэр.

Для новичка — основной экран чтобы понять «что происходит».

## 🗺 Карта

> 🟢 Работает в MVP.

Карта России с регионами и городами. В MVP открыты Москва (12 округов) и Подмосковье (56 городов).

Цвета:
- 🩶 Серый — нейтральный регион.
- 🔵 Синий — занят твоей страной.
- 🔴 Красный — занят чужой страной.

Иконки:
- 👑 на столице региона.
- 🏠 на твоём городе прописки.

Действия:
- Тап по региону — плашка с инфой (название, население, площадь, мэр, партия).
- Pan / zoom двумя пальцами.

POST-MVP:
- Сетка лотов 1 км² на максимальном zoom.
- Подсветка свободных Territory для предпринимателей.
- Подсветка регионов доступных к захвату для воинов.

## 🏭 Постройки

> 🟢 Каталог работает. 🟡 Стройка с Territory — POST-MVP.

Каталог всех 27 типов зданий. Вкладки по секторам: Ресурсы / Пища / Энергетика / Жильё / Сервисы.

На карточке здания:
- Иконка + название.
- Что производит и сколько в день.
- Стоимость стройки (ресурсы + ₽).
- Сколько рабочих нужно.
- Окупаемость.

Действия:
- Тап — открыть детали.
- «Построить» (POST-MVP) — выбор Territory + начало стройки.

## 💰 Финансы

> 🟢 Работает в MVP.

Бот-рынок:
- Цены на все 21 ресурс.
- Скупка ботом (×0.5 от рыночной) — быстро продать.
- Продажа ботом (×5 от рыночной) — быстро купить.

Твои офферы (если выставил) и история сделок.

Действия:
- «Продать боту» — мгновенно.
- «Купить у бота» — мгновенно (если есть деньги).
- Выставить оффер другим игрокам — POST-MVP.

## 👤 Профиль

> 🟢 Работает в MVP.

Карточка:
- Имя, аватар, уровень, навыки, прописка.
- Финансы — ₽, GP, энергия / максимум.
- Активы — заводы и Territory (с разделом по городам).
- Должности — действующие позиции.
- Теги активности — entrepreneur / worker / politician / pmc_member / ...

Действия:
- Публичный профиль другого игрока — POST-MVP.
- «Перевести деньги» — POST-MVP.
- «Сменить активный навык» — POST-MVP.
- «Сменить прописку» — POST-MVP.

## Работа

> 🟡 POST-MVP (спека 8.8, следующая в плане).

Открывается из Главной или Профиля. Внутри — список всех вакансий в твоём городе:
- Список заводов с открытыми слотами.
- Условия каждого: тип оплаты (cash / share / mixed), ставка, количество мест.
- Расчёт твоей выгоды с учётом навыков.
- «Поработать» — слайдер «сколько энергии вложить», деньги или ресурс приходит сразу.

## Статистика города

> 🟡 POST-MVP.

Открывается из Главной → «Подробнее о городе». Детали родного города или города в управлении (если ты мэр):
- Население по классам.
- Удовлетворённость / голод / достаток.
- Производство и потребление.
- Бюджет и налоги.
- Гордума (состав, голосования).

Доступ зависит от роли:
- Жители — базовая статистика.
- Мэр — полный контроль (бюджет, ставки, цены Territory, министры).
- Губернатор — то же на уровне региона.

## Карточка здания

> 🟢 Просмотр работает. 🟡 Управление XP — POST-MVP.

Открывается из **Постройки** тапом по конкретному зданию. Внутри:
- Owner (city_gov / private_player / country_gov).
- Состояние (operating / damaged / construction).
- Production и Buffer.
- XP накопленный.
- Сотрудники.

Действия (POST-MVP):
- Прокачка через XP (+5% production, +10% buffer и т.д.).
- Найм / увольнение.
- Изменение wage_mode.

## Иконка часов в хедере

> 🟢 Работает в MVP.

В правом верхнем углу — игровое время. Тап → тултип:

```
📅 Игровое время: 07:00, день 14, год 3
   1 тик (1 мин реал) = 1 игровой час
   1 игровой день = 24 минуты реал
   1 игровой год ≈ 6 дней реал
   Сезон: лето
   Следующий тик через 0:25
```

Единственное место в UI где объясняется конвертация. В остальных — всё в игровых днях («100 кг/день», «20k ₽/день», «2 дня до истечения»).

## Push-уведомления

Telegram шлёт пуши:
- За 1 игровой день до истечения скоропортящегося товара на складе.
- При появлении просрочки.
- При начале голосования в Гордуме / Госдуме (если ты депутат).
- При объявлении войны твоей стране / партии.
- При выкупе или нападении на твою Territory.

Настройки — в Профиле → Уведомления (POST-MVP).
