> Status: 🟢 реализовано.

Игровой мир организован как вложенная иерархия: страна содержит регионы, регионы, города, города, земельные лоты, на лотах строятся здания.

## Структура мира

```
Страна
├── Президент — глава, NULL = страна «спящая» (не основана)
├── Столичный регион — NULL пока страна не основана
│
└── Регион (субъект страны)
    ├── Губернатор — NULL = нейтральный
    ├── Столичный город региона
    ├── Правящая страна — какой стране принадлежит, NULL = нейтральный
    │
    └── Город (или округ)
        ├── Мэр — NULL = нет мэра
        ├── Правящая страна — NULL = нейтральный
        │
        └── Лот земли (Territory, 1×1 / 5×5 / 20×20 км)
            ├── Владелец: мэрия / игрок / государство
            │
            └── Здание (Building)
                ├── Владелец: мэрия / игрок / государство
                └── Тип: завод / магазин / школа / больница / ...
```

## Авто-наследование власти через столицы

Президент по должности правит **всей цепочкой**: страна → столичный регион → столичный город. Без отдельных полей «губернатор столицы» / «мэр Кремля».

Логика резолвера:

```
глава региона(регион) =
  если регион = столичный регион страны → Президент
  иначе                                  → Губернатор

глава города(город) =
  если город = столичный город региона → глава региона(регион)
  иначе                                 → Мэр
```

**Почему так:** реальные деньги, ресурсы и оборона страны находятся в «Кремле» (столичный город столичного региона). Захватить страну = захватить Кремль. Президенту не нужны параллельные роли «Губернатор столицы» и «Мэр Кремля».

## Типы регионов и городов

### Типы региона

| Тип | Назначение | Лейбл UI |
|---|---|---|
| Область | Подмосковье, Калужская и т.д. | «область» |
| Республика | Татарстан, Башкортостан | «республика» |
| Край | Алтайский, Краснодарский | «край» |
| Город федерального значения | Москва, СПб, Севастополь | «город федерального значения» |
| Автономная область | | «автономная область» |
| Автономный округ | | «автономный округ» |

### Типы города

| Тип | Назначение | Лейбл UI |
|---|---|---|
| Столица региона | Динамическая, может меняться | «региональный центр» |
| Город | Обычный город или городской округ | «город» |
| Село | | «село» |
| Посёлок | | «посёлок» |

### Особый случай: Москва

Москва, это **город федерального значения**. Внутри Москвы как региона лежат 12 округов-городов:

- ЦАО: столица Москвы по умолчанию.
- САО, СВАО, ВАО, ЮВАО, ЮАО, ЮЗАО, ЗАО, СЗАО, Зеленоградский АО, Новомосковский АО, Троицкий АО: обычные города (тип «город»).

Дубля «регион + город» с одним именем нет: ЦАО это город, Москва это регион.

## Стартовое состояние и расширение мира

**На старте никаких государств не существует.** Страна РФ есть в базе с пустым Президентом. Все регионы нейтральны. Государство **рождается** когда первая партия захватывает первый нейтральный регион через войну с NPC-армией. См. [Пути к власти](/player-guide/paths-to-power/).

**Тестовый сценарий в seed:**

- 🇷🇺 **Российская Федерация:** основана тестовым профилем 1003 «Президент РФ».
 - Москва (столичный регион): ЦАО (столичный город), САО (мэр 1002), ВАО (приватный завод 1004), 9 других округов нейтральные.
- ⚪️ **Подмосковье:** нейтральный регион, 56 городов, все нейтральные.

**Автоматическое расширение:** при добавлении новых регионов в базу (например СПб) карта подхватит их автоматически, если в TopoJSON есть нужный feature. Без правок UI-кода.
