# Grand Regions — Документация

> Политическая онлайн-стратегия в Telegram Mini App. Игроки управляют регионами реальной (РФ) или вымышленной карты, ведут экономику, политику, армию в реальном времени.

> 🌐 **Сайт:** https://wiki.grand-regions.com (зеркало на https://aolychkin.github.io/grand-regions-wiki/).
>
> 🔄 Этот репозиторий — **автоматический публичный mirror** директории `docs/` приватного репо проекта. Правки делаются там → синкаются сюда GH Action'ом. PR на этот репо тоже принимаются — переносятся в основной вручную.
>
> 📄 **Лицензия:** [CC BY-SA 4.0](LICENSE) — копировать, переводить, делать производные при указании авторства и под той же лицензией.

Содержание:

- 📖 [Гайды для игроков](player-guide/) — как играть, зарабатывать, расти от жителя до Президента.
- ⚙️ [Игровые механики](game-mechanics/) — иерархия мира, стройка, экономика заводов, налоги.

## Статусы

- 🟢 **Реализовано в MVP** — фича работает в коде.
- 🟡 **Запланировано (POST-MVP)** — есть в roadmap, ждёт спеки.
- 🔴 **Концепт** — пока только в game-design, без оценки реализации.

Все актуальные правила игры — в этих документах. Когда появится механика — статус меняется на 🟢.
